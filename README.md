# Solar Power Generation Prediction

## 1. Project Overview

The Solar Power Generation Prediction project uses Machine Learning to estimate daily solar energy generation based on environmental conditions and solar panel information.

The project uses a Random Forest Regressor to predict solar power output and a Streamlit web application to display the prediction results.

## 2. Objectives

- Predict daily solar energy generation.
- Understand how weather conditions affect solar power output.
- Classify predicted output as LOW, MODERATE, HIGH, or VERY HIGH.
- Provide a simple, interactive web interface.
- Help users understand solar energy generation through predefined FAQs.

## 3. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Regressor
- Streamlit
- Joblib

## 4. Dataset Information

The project uses a solar power dataset containing environmental and solar panel features.

| Column | Description |
|---|---|
| Date | Date of observation |
| Temperature_C | Temperature in degrees Celsius |
| Humidity_pct | Relative humidity percentage |
| Wind_Speed_kmh | Wind speed in km/h |
| Solar_Irradiance_Wm2 | Solar irradiance in W/m² |
| Cloud_Cover_pct | Cloud cover percentage |
| Panel_Tilt_deg | Solar panel tilt angle |
| Power_Output_kWh | Daily solar energy generated in kWh |

The target variable is `Power_Output_kWh`.

Dataset file: `solar_power_dataset.csv`

## 5. Machine Learning Algorithm

**Algorithm:** Random Forest Regressor

Random Forest is an ensemble learning algorithm that combines predictions from multiple decision trees to estimate a numerical value.

It is suitable for this project because it can model nonlinear relationships between weather conditions and solar energy generation.

The project uses the following workflow:

1. Load the dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Clean the data and handle missing values.
4. Extract month and day of year from the date.
5. Split the data into training and testing sets.
6. Train the Random Forest Regressor.
7. Evaluate the model using MAE, RMSE, and R².
8. Save the trained model using Joblib.
9. Use the model in a Streamlit application.

## 7. Installation

### Step 1: Open the project folder

Open a terminal in the project directory.

```bash
cd C:\solar_power_prediction
```

### Step 2: Install the required libraries

```bash
py -m pip install -r requirements.txt
```

### Step 3: Train the model

```bash
py solar_power_prediction.py
```

This script performs data analysis, trains the model, evaluates its performance, and saves `solar_model.pkl` if the model-saving code is included.

### Step 4: Start the web application

```bash
py -m streamlit run app.py
```

Streamlit will display a local URL in the terminal. Open that URL in your browser to use the application.

## 8. Application Features

- User input for temperature, humidity, and wind speed.
- User input for solar irradiance and cloud cover.
- Solar panel tilt, month, and day-of-year inputs.
- Daily solar energy prediction in kWh.
- LOW, MODERATE, HIGH, and VERY HIGH output categories.
- Input summary table.
- Solar energy FAQ section.
- Interactive Streamlit interface.

The output categories use demonstration thresholds and must be adjusted to the actual solar installation's capacity and expected generation.

## 9. Model Evaluation

The trained model can be evaluated using:

- **MAE:** Mean Absolute Error measures the average absolute difference between actual and predicted values.
- **RMSE:** Root Mean Squared Error gives greater weight to larger prediction errors.
- **R² Score:** Measures how well the model explains variation in the target values.

Evaluation results depend on the dataset and test split. Results from a small synthetic or demonstration dataset may not reflect real-world performance.

## 10. Limitations

- Prediction quality depends on the quality and size of the training dataset.
- Weather can change after the prediction is made.
- The application does not directly measure electricity generated by a physical solar panel.
- Output categories are illustrative rather than universal standards.
- Predictions should not be treated as guaranteed energy generation.
